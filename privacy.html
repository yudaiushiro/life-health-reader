プライバシーポリシー / Privacy Policy

施行日 / Effective date: 2026-10-26

日本語

life health reader（以下「本ツール」）は、Yudai Ushiro が自分自身のためだけに運用する個人用・単一ユーザー向けツールです。

取得するデータ

本ツールが取得するのは、所有者本人の Google アカウントに紐づく睡眠データおよび活動・フィットネスデータのみです。データは Google Health API を通じて読み取り専用（googlehealth.sleep.readonly、googlehealth.activity_and_fitness.readonly）で取得します。所有者以外の人物のデータは取得しません。

利用目的

取得したデータは、所有者本人に自身の睡眠と活動の要約を表示する目的にのみ使用します。

共有・販売・広告

データを販売することはありません。第三者と共有・譲渡することはありません。広告の目的に使用することはありません。

保存

データは所有者本人のコンピュータ上にのみ保存され、本ツールの運営者が管理する外部サーバーには送信・保存されません。

アクセスの取り消し

本ツールへのアクセス許可は、いつでも https://myaccount.google.com/permissions から取り消すことができます。

Google API サービスのユーザーデータに関するポリシー

本ツールによる Google API から受け取った情報の使用および他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用（Limited Use）の要件を含む）に準拠します。

English

life health reader ("the tool") is a personal, single-user tool operated by Yudai Ushiro for his own use only.

Data accessed

The tool accesses only the owner's own sleep data and activity and fitness data associated with the owner's own Google account. Data is accessed read-only through the Google Health API (googlehealth.sleep.readonly, googlehealth.activity_and_fitness.readonly). No data about anyone other than the owner is accessed.

How data is used

The data is used only to show the owner summaries of his own sleep and activity.

Sharing, sale, and advertising

The data is not sold. It is not shared with or transferred to any third party. It is not used for advertising.

Storage

The data is stored only on the owner's own computer. It is not sent to or stored on any external server operated by the tool's developer.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.

Google API Services User Data Policy

life health reader's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
