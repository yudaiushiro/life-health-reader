life health reader

life health reader は、Yudai Ushiroが自分自身のためだけに作成・運用している個人用ツールです。利用者はアプリの所有者本人のみです。

本ツールは Google Health API を通じて、所有者本人の Fitbit / Google Health の睡眠データおよび活動データを読み取り専用で取得し、所有者自身のコンピュータ上で動作するパーソナルアシスタントで、本人向けの要約を表示するために使用します。データの書き込み・変更・削除は行いません。

使用するスコープ（読み取り専用）：

  • https://www.googleapis.com/auth/googlehealth.sleep.readonly
  • https://www.googleapis.com/auth/googlehealth.activity_and_fitness.readonly

お問い合わせ：behindkun@gmail.com

life health reader is a personal, single-user tool built and operated by Yudai Ushiro for his own use only. The only user is the app's owner.

It uses the Google Health API to read the owner's own Fitbit / Google Health sleep and activity data, read-only, so that a personal assistant running on the owner's own computer can show the owner summaries of that data. It never writes, modifies, or deletes any data.

Scopes used (read-only):

  • https://www.googleapis.com/auth/googlehealth.sleep.readonly
  • https://www.googleapis.com/auth/googlehealth.activity_and_fitness.readonly

Contact: behindkun@gmail.com
